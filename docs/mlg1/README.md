# MLG1 Architecture & Design Pack

This folder contains the architecture and design artifacts for the approved enhancements:
- **MLG1-9**: Automated test coverage for core CRUD flows
- **MLG1-10**: Advanced search and filtering for books list

## Contents
- `architecture.md` – Architecture document (context, containers/components, NFRs)
- `diagrams/architecture.mmd` – Mermaid architecture diagram source
- `hld.md` – High-level design
- `lld.md` – Low-level design (class-level and method-level notes)
- `database-schema.md` – Database schema (existing + any additions)
- `ui-wireframes.md` – UI wireframes for the enhanced books list

> Note: Diagrams are provided as Mermaid (`.mmd`) so they render in GitHub and Confluence (via Mermaid macro or markdown renderer if enabled).
